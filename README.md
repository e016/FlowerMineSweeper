# FLOWERMINESWEEPER
**Remember minesweeper? FlowerMineSweeper is a mod of Google Minesweeper, now with:**
1. 3 lives!
2. custom board sizes!
3. anti mines and double mines!
4. (in-progress) powerup system!
5. Themes!
6. Double mines and Anti Mines
7. An work-in-progress adventure mode
8. Hey what's this
9. Why are we at nine?
10. That's it, just play the game and find out yourself.
